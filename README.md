# DataBase Prompt List

Aplicación de escritorio construida con Electron, React, Prisma y SQLite para gestionar prompts de IA.

## Autor
**Dner Shaitan**

## Tecnologías utilizadas
- Electron
- React + Vite
- Prisma ORM + SQLite
- TypeScript

## Instalación

```bash
npm install
npx prisma migrate dev --name init
npm run dev
```

## Compilar .exe

```bash
npm run build
npm run make
```
